# ✨ Magic Link Experience

A premium, cinematic web experience for creating and sharing personalized "Magic Links". Perfect for birthdays, surprises, or special messages.

## 🚀 Features
- **Cinematic Storytelling:** Multiple animated scenes using Framer Motion.
- **Personalized Reveal:** Name reveal with magical gold gradients.
- **Interactive Magic:** Custom particle effects and confetti that respond to clicks/taps.
- **Seamless Sharing:** Generates unique links stored securely in Firebase.
- **Mobile Optimized:** Designed to look stunning on both desktop and mobile devices.
- **Audio Experience:** Integrated background music for a complete emotional experience.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Animations:** Framer Motion, Three.js
- **Backend:** Firebase (Cloud Firestore & Storage)
- **Icons:** Lucide React

## 📦 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Khangulamgousamjat/Birthday-wisher-.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   Create a `.env` file and add your Firebase credentials:
   ```env
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
   VITE_FIREBASE_APP_ID=your_app_id
   VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Deploy**
   Built for easy deployment on [Vercel](https://vercel.com).
